# 🎮 Jumawa — Tetris in Pure JavaScript

**Jumawa** is a classic Tetris clone built entirely with vanilla JavaScript. This project was created as a fun way to practice logic, DOM manipulation, and build a simple browser-based game without external libraries.

---

## 🚀 Live Demo

Play it instantly in your browser:  
👉 [Jumawa Tetris Live](http://tetrisjumawa4.surge.sh/)

---

## 🧩 Features

- 🎮 **Classic Tetris Gameplay** — Rotate, move, and drop blocks  
- 📱 **Responsive UI** — Clean and adaptive design  
- ⌨️ **Keyboard Controls** — Arrow keys and optional spacebar for hard drop  
- 💥 **Game Over Detection** — Automatic end when blocks reach the top  
- 📊 **Score & Line Tracking** — Keeps track of score and cleared lines  

---

## 🎮 Controls

| Key            | Action             |
|----------------|--------------------|
| ⬅️ Left Arrow  | Move left          |
| ➡️ Right Arrow | Move right         |
| ⬇️ Down Arrow  | Soft drop (faster) |
| ⬆️ Up Arrow    | Rotate block       |
| Spacebar       | Hard drop *(optional)* |

## 🛠️ How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/le0nxD/Jumawa.git
   ```

2. **Open the HTML file** in your browser:
   Just double-click on `index.html` or open it via your browser.

3. **Play and enjoy!**
